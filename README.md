# Features:
<ol>
<li>It follows your cursor   </li>
<li> Double click and it says "Hello!" </li>
<li> Spacebar and it greets you depending on the time of day                                 </li>
<li> You can hover over it and it gets larger                                                    </li>
<li> Art used is original                                                                                     </li>
</ol>
